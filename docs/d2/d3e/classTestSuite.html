◆ RunSustained()

TestHost::SustainedSummary TestSuite::RunSustained ( const std::string & test_name,
uint32_t warmup_frames,
uint32_t measure_frames,
bool log = true,
uint32_t abort_busy_us = 0 )

Runs the given test repeatedly for warmup_frames + measure_frames frames, recording per-frame timing for the measured frames. If log is true, also logs a sustained-mode results record. If abort_busy_us is not 0, the run stops early once any frame after the first is busy for longer than that.
