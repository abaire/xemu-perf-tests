◆ WaitForGPUIdle()

bool TestHost::WaitForGPUIdle ( )

Blocks until the GPU has finished all work submitted so far.

Pushes a NV097_BACK_END_WRITE_SEMAPHORE_RELEASE and spins on the RAM value the GPU writes, rather than polling GPU registers via pb_busy(). Under xemu each register read is an MMIO access that contends for the same locks the benchmarks are trying to measure, so polling would perturb the results.

Returns false if the fence timed out, in which case this falls back to pb_busy().
