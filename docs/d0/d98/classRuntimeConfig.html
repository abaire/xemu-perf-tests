◆ RunMode

enum class RuntimeConfig::RunMode
strong
Enumerator
SINGLE 

Each test renders once (repeating its body a few times) and logs submission timing.

SUSTAINED 

Each test runs for warmup + measure frames in continuous (60fps-budget) mode and logs per-frame timing.

CALIBRATE 

Each test with a load knob is searched for the largest load that meets the frame budget, and the results are written to calibration.json.
